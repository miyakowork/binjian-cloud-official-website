# 彬剑云信息技术有限公司官网

基于 BinBot Foundation 品牌与能力构建的官网设计探索。项目同时实现三套可交互、响应式方案：

- 深海核心：面向技术决策者，突出平台架构与可靠性。
- 云端编辑：面向企业客户，突出产品体验与业务价值。
- 工程交付：面向项目负责人，突出端到端交付方法。

## 本地运行

```bash
npm install
npm run dev
```

浏览 `http://localhost:5173`，从方案总览进入三套完整页面。

## 验证

```bash
npm test
npm run build
npm run test:sites
```

当前咨询表单为安全的前端演示：数据只在页面内处理，不会向外部发送。正式上线前需接入企业联系方式、表单服务与备案信息。
