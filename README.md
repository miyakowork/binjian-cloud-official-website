# 彬剑云信息技术有限公司官网

以 BinBot Foundation 的实际基础能力为内容依据，采用移动端优先的单页企业官网设计。

## 页面内容

- 公司定位与 Foundation 能力架构
- 统一身份权限、业务接入、多租户隔离和运行治理
- 技术分层与项目建设场景
- 交付方法、公司介绍和需求清单下载

旧版三套概念页面及专属素材已移除，历史版本可从 Git 提交恢复。

## 开发和验证

```bash
npm ci
npm run dev
npm test
```

`npm test` 会先执行生产构建，再验证静态服务行为及构建产物。站点发布到 GitHub Pages，`main` 分支推送触发自动构建和部署，自定义域名为 `wx.binbotcloud.com`。

## 移动端设计

支持 320px 起的窄屏布局、折叠导航、底部快捷入口、安全区留白，以及减少动态效果偏好。输入框字号为 16px，避免手机输入时自动缩放；需求清单使用原生对话框，支持 Escape 关闭和焦点返回。

## 联系入口

尚未提供正式对外联系方式，因此入口为可下载的项目需求清单。输入内容只在当前浏览器生成文本文件，不上传、不持久化，也不表示咨询已发送。
